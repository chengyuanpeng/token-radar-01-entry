How the signal is built

SNAPSHOT-CALIBRATED
IMPLIED VALUE=TVL^0.85 · $100M scale×category multiple×growth factor×maturity factor×breadth factor

01Peer mcap/TVL ratios are winsorized to the snapshot's P5-P95 range before any median is taken, so a single 400x outlier cannot set a category price.

02Category medians shrink toward the overall median in log space (k = 6; k = 12 when a category has two or fewer live peers) and are capped at 2.5x the overall median. Thin categories are flagged THIN in each detail page.

03Implied value scales with TVL^0.85, compressing giants: doubling TVL multiplies value by about 1.8x, not 2x. Growth, maturity (tau = 540 days) and breadth factors then adjust the base.
